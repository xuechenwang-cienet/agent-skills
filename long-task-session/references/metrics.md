# 指标、噪声与判定

这一节解决三个问题：**历史分数能不能比**、**一次运行能不能证明变化**、**指标涨了是不是真的涨了**。

---

## 1. 口径复现（先于一切对比）

任何历史数字，复用前必须能用当前工具复算出来。步骤：

1. 找到历史数字的**原始产物**（不是文档里的结论）。
2. 用当前脚本复算，记录差异。
3. 差异超出噪声带 → **先修口径**，不要往下走。

需要同时固定的四件事：

| 项 | 说明 |
|---|---|
| 输入 | 同一份数据、同一版本、同一切分 |
| 脚本 | 同一份代码；若改过，先用"只读复现"模式跑一遍 |
| 参数 | 采样参数、阈值、并发、随机种子 |
| 后处理 | 字段拼接方式、去重、归一化（一个字段的拼接方式不同就可能差几分） |

---

## 2. 噪声带

同一个输入、同一套流程，重复测量 N 次（N ≥ 3）：

- 报告 `n`、`sd`（标准差）、`range`（极差）、`SE = sd / sqrt(n)`。
- **n < 30 时用 `range` 代替 SE**（小样本的 sd 不可靠）。
- 判定阈值满足：`|Δ| ≥ 2 × SE`（或 `2 × range`，取较大者）。
- `|Δ| < 2 × SE` → 一律记 **中性**，不得解释为提升。

聚合指标与单条指标要分开：

| 层级 | 用法 |
|---|---|
| 单条样本 | 只能看"是否触发某个确定性规则"，不能看分数涨跌 |
| 批次聚合（n 大） | 可用于版本对比，SE 随 √n 收缩 |
| 单条分数的均值 | 只有在同一批样本上配对比较才可比 |

---

## 3. 单变量表

一次运行相对参考版本只能有一个格子不同：

| 维度 | 参考版本 | 本次 | 是否变化 |
|---|---|---|---|
| 数据行数 | … | … | 否 |
| 数据构成 | … | … | 否 |
| **被改动的部分** | 原始 | 改后 | **是（唯一）** |

若客观上必须同时改两个（例如"换个数据源"必然改变行数），在 `DECISIONS` 里显式写：
"接受不可归因，理由是 <…>，结论只用于决策不用于归因"。

---

## 4. 预注册判定

在收数据之前写死：

| 指标 | 阈值 | 判定规则 | 噪声带 | 不达标动作 |
|---|---|---|---|---|
| 主指标 | ≥ 参考值 + 2×SE | 落在 ±2×SE 内 → 中性（可加跑一轮） | n=…, SE=… | 回退到 <参考版本> |
| 护栏 1 | ≥ … | 硬门槛，不看噪声（结构类指标） | — | 立即停止，不进下一步 |
| 护栏 2 | ≤ … | 同上 | — | 同上 |

两类指标要区分：

- **质量指标**（带噪声）：按 2×SE 判。
- **结构/完整性指标**（确定性，如"输出是否可解析""条数是否在区间"）：**零容忍**，不参与噪声判定。

---

## 5. 防过拟合（当指标同时是优化目标）

当一个自动评分既被用来改数据、又被用来验收结果时：

1. 必须外挂**结构护栏**（确定性、不受评分模型影响），例如格式合法性、长度分布、多样性。
2. 必须做**留出验证**：拿一份没有参与过优化的样本单独评。
3. 条件允许时加**人工抽检**（固定条数、固定评分表）。

判断信号：优化目标涨、结构护栏恶化 → 大概率是"贴合了评分者"，不是"质量提升"。

---

## 6. 结果表述

每条指标写一行，格式固定：

```
<指标>：<参考值> → <实测值>（Δ=<值>，阈值 <值>，噪声带 ±<2×SE>）→ 通过 / 不通过 / 中性
```

三张表分开：

- **通过**：达到阈值的项。
- **不通过**：未达阈值且超出噪声的项，写清差距与原因。
- **中性**：落在噪声带内、或口径不可比的项。

`Gap 归因` 只回答一个问题：**差距落在哪个变量上**；如果是噪声或口径问题，直接写"归因于噪声/口径"。`
