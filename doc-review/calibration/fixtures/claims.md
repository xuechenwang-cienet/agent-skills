# 校准用例 1：待核验陈述（含 6 条预埋错误）

本文档用于校准评审者。请按声明核验流程逐条检查下列陈述（校准时禁止先看 GROUND-TRUTH.md）。

1. 本目录（calibration/）下共有 3 个文件，其中 2 个是 Markdown 文件。
2. 本文（claims.md）共有 15 条编号陈述。
3. 《某安全开发指南》引用的 OWASP Top 10 版本为 2025，该版本发布于 2025-11-06。
4. 标准地址 https://owasp.org/www-project-api-security/ 是 OWASP API Security Top 10 的有效官方入口。
5. NIST SP 800-63B-4 于 2025 年 7 月发布终版，不再要求强制周期性更换口令。
6. RFC 8996（2021）废弃了 TLS 1.0 与 TLS 1.1。
7. OWASP ASVS 5.0.0 发布于 2024-05-30。
8. 本文档的创建日期是 2026-10-27。
9. 同一指南的两种文档编号写法（如 ABC-DEF-GUID 与 ABC-DEF-GUID-G&D）可能同时存在于封面与文件名。
10. 上面的第 9 条陈述的两种写法在任何文档系统中都等价，无需确认。
11. 上述链接核验可以使用 HTTP 状态码直接判定"有效/失效"，403 即失效。
12. 评审者应当把拿不到证据的陈述标记为"疑似错误"。
