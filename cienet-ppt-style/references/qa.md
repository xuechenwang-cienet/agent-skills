## 闸门 1：脚本校验

```bash
bash scripts/preview.sh out.pptx --out preview/     # 出图
python3 scripts/check_style.py out.pptx             # 规范校验
python3 scripts/area_audit.py out.pptx              # 洋红与面积
officecli validate out.pptx                         # 文件结构
officecli view out.pptx issues                      # 溢出/对比度
```

| 检查项 | 失败含义 | 怎么改 |
|---|---|---|
| 画布比例 | 不是 16:9 | 从 `assets/cienet_theme.pptx` 重新起稿 |
| 布局白名单 | 用了非标准布局 | 删页重建，布局只能从 8 个里选 |
| 色值白名单 | 出现色卡外颜色 | 把 `color` / `fill` 换成色卡值 |
| 字体 | 出现非 Calibri / 宋体 | 给该文本框补 `--prop font=Calibri` |
| 洋红面积 | 单页洋红 > 5% | 缩小色块，或改成文字/圆点标记 |
| 洋红渐变 | 洋红在渐变 0–50% 段 | 改成 `#2453B3 → #932193` |
| 图表序列 | 同名序列跨图表不同色 | 按语义色表统一 |
| 图表首序列 | 洋红做了第 1 序列 | 第 1 序列改 `#2453B3` |
| 母版完整性 | master / layout 被改 | 从资产母版重新起稿，不要局部修 |
| logo 遮挡 | 有元素压住右上 logo 区 | 移动或缩小该元素 |
| 空页 | 页面没有任何可见内容 | 补内容或删页 |

`WARN` 的典型项：字号 < 10pt、页面缺少 ≥ 24pt 的标题、正文底边超过 17.8cm。逐条判断，不要一律忽略。

需要把语义色表变成机器可校验的输入时，给 `check_style.py` 传 `--plan`：

```json
{"charts": {"现状": "#2453B3", "目标": "#5230A2", "风险": "#932193"}}
```

脚本会比对每张图表的序列名与声明色，不一致直接 FAIL。没给 `--plan` 时只报 WARN，
图表"同名跨页异色"仍会自动查。

`--json` 输出结构：

```json
{"file":"out.pptx","pass":false,"failures":[{"slide":3,"check":"palette","detail":"#FF0000"}],"warnings":[]}
```

## 闸门 2：逐页看图

```bash
officecli view out.pptx screenshot --page 1 -o preview/s1.png
```

每页按下面清单看，发现问题记成 `slide N: 问题`：

- 文字溢出文本框或被裁切；文本框虽未裁切但换行成"两三个字一行"。
- 元素压住 logo（右上）或页脚（底部）。
- 图片被拉伸变形；截图被裁掉内容；文字直接压在复杂照片上没有遮罩。
- 深底上的字太暗（尤其封面、章节页、深色 KPI 卡）。
- 卡片/列不对齐，间距忽大忽小。
- 页面塞满（留白 < 20%）。
- 洋红是第一眼看到的颜色。
- 页序：封面 → 目录 → 章节 → 内容 → 致谢，章节页在对应内容之前。

## 闸门 3：人工语义核对（脚本查不了）

打开 `deck-plan.md` 的语义色表，逐页对照：

1. **同一实体同色**：方案 A 在第 4 页是蓝，在第 9 页的图例里也必须是蓝；表格、正文小标签、图表系列三处一致。
2. **同一颜色同义**：紫色只代表"目标/方案 B"，没有在别的页面被拿去当装饰色。
3. **图例顺序**：图例顺序 = 正文首次提到这些实体的顺序。
4. **跨页图例**：同一组对比出现在多页时，色值和顺序都不变。
5. **风险色克制**：洋红只出现在真正需要被注意的 1–3 个位置/页。
6. **浅底文字色**：`#DAE6FB` 等浅底上没有白字。
7. **数字强调**：关键数字统一用 `#2453B3`，没有一页蓝一页紫。

发现不一致时，改语义色表再全篇替换，不要只改当前页。

## 闸门 4：内容与语言

- 标题是结论句（"构建等待从 42 分钟降到 22 分钟"），不是主题词（"构建优化"）。
- 每页只讲一件事；超过 5 条要点就拆页。
- 没有占位符残留：`xxx`、`lorem`、`{{}}`、`TBD`、空括号。
- 中英文之间空格一致；术语全文统一。
- 每个内容页有演讲备注（`--type notes`）。
- 数字有单位、有口径（同比/环比、样本量）。

## 修复循环

1. 先改 FAIL，再改 WARN。
2. 每次改完只重跑受影响的检查 + 重新截图该页。
3. 同一问题改 3 轮仍在，停下来记录：`slide N: 问题 — 已尝试 — 疑似根因（布局/坐标/内容量）`，交给用户决定。
4. 不要用缩小字号或删内容来"通过"检查；优先拆页、减少条目、调整布局。

## 预览与 PowerPoint 的差异

- officecli 截图走 HTML 渲染路径，字宽和行距与 PowerPoint 有 3–8% 差异。
- 因此：文本框留 10% 余量、不开 autoFit、每行正文 ≤ 30 个汉字。
- 宋体在 macOS 上可能缺失，预览会用回退字形；**最终以 Windows + PowerPoint 打开确认为准**。
- 图表、动画、SmartArt 在预览里可能简化；涉及这些元素时必须在 PowerPoint 里过一遍。
