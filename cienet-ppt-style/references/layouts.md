# 布局与栅格

画布 33.87 × 19.05 cm（16:9，12192000 × 6858000 EMU）。所有坐标单位 cm，原点左上角。

**officecli 的 `--prop layout=` 只写元数据，不会生成占位符。** 布局里的版式装饰（logo、页脚、渐变条、页码）会继承，但标题/正文要用 textbox 按下面的坐标自己加。这也是坐标表必须写死的原因。

| 底部渐变条 | y 18.80, h 0.25, 通栏 | 蓝→紫渐变 |

- logo 区 `x > 31.5 且 y < 2.5` 不放任何东西

## 2. `TITLE`（照片封面）

| 槽位 | 坐标 (x, y, w × h) | 字号 / 颜色 |
|---|---|---|
| 主标题 | 4.24, 4.53, 25.40 × 5.01 | 48pt bold `#FFFFFF`，居中 |
| 副标题 | 4.24, 10.53, 25.40 × 2.86 | 24pt `#FFFFFF`，居中 |

照片是满版蓝色光纤图，文字直接压在上面可读性不足。加一层**中部**遮罩（不要整页盖住 logo 和页脚）：

```bash
officecli add out.pptx "/slide[N]" --type shape --prop preset=rect --prop line=none \
  --prop x=2.5cm --prop y=4.2cm --prop w=28.8cm --prop h=10cm --prop fill=#1A1A1A66
```

遮罩先加、文字后加（后加的在上面）。幻灯片上的图形会盖住布局装饰，所以遮罩不要铺到 `y<2.5` 或 `y>17.5`。

## 6. `Title and Content`（标准内容页）

| 槽位 | 坐标 (x, y, w × h) | 字号 / 颜色 |
|---|---|---|
| 眉标 | 0.68, 2.45, 30.62 × 1.20 | 20pt bold `#6D97D2` |
| 标题 | 0.68, 0.64, 30.62 × 1.75 | 32pt bold `#1A1A1A` |
| 正文 | 1.26, 4.09, 31.39 × 13.07 | 20–24pt `#1A1A1A`（布局默认 28pt，只在 ≤3 条要点时用） |

- 标题写结论，不写"概述/介绍/方案"这类主题词。
- 正文每行 ≤ 30 个汉字，全页 ≤ 5 条；超了拆页，不要缩到 16pt。
- 需要配图时：文字收窄到左半 `1.26, 4.09, 14.5 × 13.07`，图放 `17.0, 4.09, 14.3 × 11.5`（保持比例，不拉伸）。
- 眉标可省；省掉时标题仍在 0.64。
- 布局里烘焙的标题槽是 1.38cm、眉标是 0.87cm；上表给的高度略大，是为了让 officecli 的溢出检查（`view issues`）通过。PowerPoint 里两种高度都放得下，不要为了"贴合槽位"把高度改回去。

## 栅格与间距

- 页边距：左右 ≥ 0.68cm（推荐 1.26cm），上下 ≥ 0.64cm。
- 卡片/列间距固定 0.76cm 或 1.27cm，整份材料只选一个。
- 三栏卡片：可用宽 = 33.87 − 2×1.26 − 2×0.76 = 29.83，单栏 9.94cm。
- 留白 ≥ 20%：宁可少放一个卡片，不要把页面塞满。

## 页面背景

- 内容页、双栏页、目录右半区：保持白色，**不要**设置 `background`。
- 封面/致谢：由布局自带图片背景，**不要**替换或叠加整页色块。
- 只有 `DEFAULT_1` 需要深色声明页时，可设 `--prop background=#1A1A1A`，文字改 `#FFFFFF`；同一份 deck 最多 1 页这样做。
