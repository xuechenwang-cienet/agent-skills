## 洋红使用规范

`#932193` 是警告/风险色，不是主题色。大面积使用会让整份材料显得焦躁，也压掉真正需要被注意的信息。

**面积上限**：单页内所有洋红填充（shape、表格单元格、图表系列折算面积）合计 ≤ 页面积 5%。页面积 645 cm²，即约 32 cm²（例如 5.6×5.6cm 的方块）。

| 场景 | 判定 |
|---|---|
| 整页背景、章节页底色 | 禁止 |
| 大于 8×4cm 的色块 | 禁止 |
| 表格整行 / 整列底色 | 禁止 |
| 面积型图表（柱、条形、饼、面积）的大块系列 | 禁止 |
| 卡片右上角 0.6cm 圆点、`风险` 标签底 | 允许 |
| 关键数字下方 3cm×0.15cm 短横线 | 允许 |
| 1.5pt 强调线、细轮廓 | 允许 |
| 折线图/散点图的小标记 | 允许 |
| 封面/致谢页母版自带背景图里的洋红 | 例外，不计、不改 |

**图表额外规则**

- 洋红不得作为第 1 序列（第 1 序列是被比较的基准，必须用 brand-blue）。
- 饼图/环形图里洋红的扇区 ≤ 1 个，且扇区占比本身 ≤ 10%。
- 折线图用洋红时线宽 ≤ 2pt，配合 `#932193` 的数据点，不要填充线下面积。
- 图例里洋红项的标签必须写清它代表"风险/异常"，不要让读者猜。

**渐变额外规则**

- 允许：`#2453B3 → #932193`（洋红在 100%）、`#5230A2 → #932193`（洋红在末端）。
- 禁止：反向（洋红在 0%）、洋红居中且两侧都是浅色、洋红占 stop 区间 ≥ 50%。
- `check_style.py` 会解析 `gradFill` 的 stop 位置，洋红出现在 0–50% 区间直接 FAIL。

**判定自检**：把整页缩到 25% 看，如果洋红是第一眼看到的颜色，就已经过量。

## 语义配色

原则：**颜色是实体的身份证**。同一种东西在任何一页都是同一个颜色；换了颜色就等于换了对象，读者会跟丢。

### 固定语义（全公司通用，不随 deck 改）

| 语义 | token | 说明 |
|---|---|---|
| 现状 / As-Is / 基线 | `#2453B3` | 被比较的基准，永远是蓝 |
| 目标 / To-Be / 新方案 | `#5230A2` | 永远是紫 |
| 风险 / 问题 / 告警 / 阻塞 | `#932193` | 只做小面积标记或文字 |
| 中性 / 其他 / 未涉及 | `#5A5A5A` | 并列分类里的"其它" |
| 正向结果 / 达成 / 通过 | tint-blue 底 + `#2453B3` 文字或图标 | 不用绿色（色卡没有绿色） |
| 强调数字 | `#2453B3` | KPI 大数字、关键百分比 |

### 自由语义（每份 deck 自己定，但要先定后画）

按面积从大到小分配，避免深色铺满：

| 元素面积 | 用色 |
|---|---|
| 大块（卡片底、分区底、表头、整列） | tint-blue / tint-purple / tint-pink |
| 中等（色块、中等柱、图例块、流程框） | brand-blue / brand-purple |
| 极小（点、线、图标、标记、短标签） | brand-magenta |

超过 3 个并列实体时，第 4 个起用 `#5A5A5A` 和三个 tint 的组合，不要新造颜色。

### 三个场景示例

**方案 A/B 对比**：A=`#2453B3`，B=`#5230A2`。柱状图、对比表左右列、正文里的"方案 A/B"文字前的小色块，全部同色。风险备注用洋红圆点，不用洋红柱子。

**现状 vs 目标**：现状=`#2453B3`，目标=`#5230A2`。所有页（问题页、方案页、收益页）都保持这个对应，不要在第 5 页把"目标"画成蓝色。

**模块 × 风险**：模块本身用 tint 底 + 深色文字；风险等级用洋红小标签（`高`/`中`）与 `#5A5A5A` 小标签（`低`）。不要用整行洋红表示高风险。

## 图表配色

| 序列序 | 色值 | 适用图形 |
|---|---|---|
| 1 | `#2453B3` | 任意（基准序列固定用它） |
| 2 | `#5230A2` | 任意 |
| 3 | `#932193` | 仅细线/散点/小标记；面积型图表慎用 |
| 4 | `#5A5A5A` | 中性/其它 |
| 5 | `#DAE6FB` | 堆叠图的辅助层（配深色描边） |
| 6 | `#E7E6F8` | 同上 |

规则：

- 序列颜色由**语义**决定，不按"第几个系列"机械套色。语义表里"方案 B = 紫"，它出现在第 2 个还是第 5 个图表里都必须是紫。
- 同名序列跨图表必须同色（`check_style.py` 自动比对）。
- 超过 6 个序列：拆图或改表格，不要新增颜色。
- 图例顺序与正文首次出现顺序一致。

## 对比度

| 底色 | 文字色 |
|---|---|
| 白 / 三个 tint | `#1A1A1A`（正文）、`#5A5A5A`（次要）、`#2453B3`（强调） |
| `#2453B3` / `#5230A2` / `#932193` / `#1A1A1A` | `#FFFFFF` |
| 深色渐变（封面、致谢） | `#FFFFFF`、`#E8EEF8`、`#D8E2F2` |

- tint 底上禁止白字；品牌色块上禁止黑字（对比度不足 4.5:1）。
- 投屏环境偏亮，正文对比度按 4.5:1 起步，不要用中灰 `#5A5A5A` 做 18pt 以下的正文。

## 禁止事项

1. 色卡外的任何色值，包括"看起来差不多"的蓝。
2. 绿 / 橙 / 黄 / 红等语义色（预警用洋红，正向用 tint-blue + 蓝）。
3. 纯黑 `#000000` 大面积背景（用 `#1A1A1A` 或深色渐变）。
4. 用透明度制造"新颜色"（例如 50% 的蓝色）来当独立色使用；透明度只用于遮罩。
5. 同一页出现 4 个以上高饱和色块。
6. 洋红整页/整块/整行使用。
